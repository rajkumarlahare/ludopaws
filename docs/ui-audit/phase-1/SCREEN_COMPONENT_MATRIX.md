## Suggested migration order

1. Shared semantic tokens and icon contract.
2. Home pilot; review before broader migration.
3. Settings and Friends with explicit accessibility checks.
4. Profile, Store and Leaderboard.
5. Online and Team Up, using only stable repeated primitives.
6. Gameplay edges (back/settings controls only); leave board, rules and proof paths untouched.
